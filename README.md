# FeelingFrenzy

A 2D mobile game ("Kimochis Feeling Frenzy") developed for **Plushy Feely Corp.** (the company behind the *Kimochis* brand), using the **ShiVa 3D** engine with **Lua** scripting, targeting Android and iOS. This repository preserves the full project: Lua game scripts, ShiVa resources and scenes, artist source art, audio, and historic mobile export builds (`.ipa` / `.apk`). The game is no longer available on the App Store or Google Play.

> **This project is shared ONLY for educational purposes. Its use, direct or derived, for professional or economic purposes is not permitted.**

**Note on security**: for security reasons, some parts of the project are not published here (Apple signing certificates, provisioning profiles and private keys originally present in the project folder, plus internal documentation).

## Credits

- Final game graphics: **Saponia.com**
- Project: developed for Plushy Feely Corp. (Kimochis)
- Code / game logic: Fernando Ruiz (Fernans)

## Requirements / How to run

- **ShiVa 3D engine** (ShiVa Editor, era 2010-2011 builds): open the project via `Project.cfg`.
- Scripts are written in **Lua** (see `Resources/Scripts/`).
- Final targets were Android and iOS builds found under `Exports/` (historical artifacts — they will not run on current OS versions).
- The `Final_Backup` distribution package is attached as **GitHub Release assets** (it exceeds the normal git file limit).

Raw artist material can be found under `Santis/`, and mockup screens under `Fer/`.
